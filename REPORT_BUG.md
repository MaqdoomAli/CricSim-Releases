# Report a CricSim problem

Please post your bug or feedback in the PlanetCricket release thread, with:

- Game build: **CricSim v12 Alpha 1.4** (or your exact version).
- Browser and OS (for example, Chrome on Windows 11).
- Mode/format: Quick Match, IPL, Test, ODI, T10, The Hundred, etc.
- Steps to reproduce (team/squad, fixture, any special rules).
- What happened vs what you expected.
- Screenshot or exported **scorecard/match report** if relevant.
- Player batting/bowling rating when reporting unusually good or bad performances.
- For save problems: whether you used browser storage, Portable Save Folder or JSON backup, and whether the folder said **verified**.

**Privacy:** Never share personal files, secrets, browser profiles or full user save folders publicly. Export only what is needed to demonstrate the issue. Back up before experimenting.
