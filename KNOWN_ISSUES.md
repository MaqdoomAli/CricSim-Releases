# Known limitations — Alpha 1.4

- **Keep backups.** This is not a certified stable release. Avoid resetting your browser data or deleting the portable folder while investigating missing saves.
- **Physical save migration:** A real cold browser restart and actual PC-to-PC restore have not been fully administrator-certified. Save Now → Verify Folder → copy entire folder → Restore from Folder.
- **Browser compatibility:** Portable folder features rely on File System Access capabilities best supported in Chrome/Edge; folder permission can require renewal. Full-universe JSON export/import is a fallback.
- **Specialty formats:** Hong Kong Sixes and Beach Cricket still need complete P12E injury support; standard full-XI matches/competitions are covered.
- **Forum styles:** Custom PlanetCricket BBCode requires forum administrator installation; use normal/plain BBCode until enabled.
- **Realism watch:** Occasional 9–10/20 bowlers receive extensive overs, and some 12/20 batters frequently have excellent seasons. More public playtest data is requested before adjusting ratings or engine.
- **Large universes:** Long-running save sizes and actual disk/browser quotas still need broader testing. Do not run two active game sessions against the same portable folder.
