## CricSim v12 Alpha 1.4 — first public PC playtest

**Download:** `CricSim_v12_Alpha1_4_Playtester.zip` from this release (not the automatic “Source code” ZIP).

Extract the ZIP, open `CricSim_v12_ALPHA1_4_Portable_Save_Folder.html` in Chrome/Edge and start playing. Read `START_HERE_PLAYTESTERS.md` for the setup and saving guide.

Highlights: 11-a-side formats, IPL seasons and playoffs, detailed match reports, stats, optional injuries and batting retirements, and an opt-in portable folder for complete game snapshots.

**Alpha status:** Make backups. Cross-PC save restore and some unusual modes still need playtesting. The custom PlanetCricket styling needs forum administration; plain BBCode is available in the meantime.

Please post bugs and feedback in the PlanetCricket thread. The report checklist and known limitations are in the repository.
