# CricSim v12 Alpha 1.4 — Release notes

**Status:** Public playtest candidate, not yet production-certified.

## Highlights

- Full offline browser game distributed as one HTML file.
- Alpha 1.3: optional P12E retirement/injury controls in standard full-XI match and tournament paths. An 11-player squad is protected from spontaneous bowler injuries, while batters may still retire hurt.
- Alpha 1.4: optional user-selected portable save folder, verified complete snapshots, older recovery copies and an explicit restore flow for another PC. Standard browser save and full-universe JSON import/export remain available.
- A PlanetCricket-specific enhanced publishing option is available in-game, subject to forum-side installation by the site administrators. Plain BBCode remains available. The administrator installation kit is **not** part of the player release.

## IPL stress test

- 25 completed independently seeded IPL seasons using the Alpha 1.3 match engine; 1,850 matches, including playoffs, and no browser simulation exceptions.
- Alpha 1.4 changes the saving layer, **not** the underlying ball-by-ball match engine.
- Some 12/20 batters had outstanding seasons, and occasional lower-rated part-time bowlers received heavy workloads. These are calibration audit points, not proof of bugs.

See [IPL25_STRESS_REPORT.md](./IPL25_STRESS_REPORT.md) for details and [KNOWN_ISSUES.md](./KNOWN_ISSUES.md) for limitations.
