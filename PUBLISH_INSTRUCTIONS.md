# Publish CricSim Alpha 1.4 — players only

This is the **public-facing** package. Do not publish the private HFCricSim source repository, personal saves, or the PlanetCricket administrator installation package.

1. At https://github.com/new create **CricSim-Releases** as **Public**. Leave the development repository **MaqdoomAli/HFCricSim** private.
2. Extract `CricSim_Alpha1_4_Public_GitHub_Player_Only.zip`. Upload its contents using **Add file → Upload files**, then commit.
3. Open **Releases → Draft a new release**. Tag `v12-alpha.1.4`, title `CricSim v12 Alpha 1.4 — Public Playtest`. Copy `RELEASE_BODY.md` into the release description.
4. Attach **only** `CricSim_v12_Alpha1_4_Playtester.zip` as the playable download. Publish.
5. Share the public release link on PlanetCricket.

Inside the player ZIP: the standalone offline HTML game, `START_HERE_PLAYTESTERS.md`, and `KNOWN_ISSUES.txt`.

The custom PlanetCricket forum BBCode/CSS installer was already submitted to the forum admins. Do **not** distribute that installer to playtesters. If the forum-side upgrade is not yet active, players can use the normal BBCode exporter.
